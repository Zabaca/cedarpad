Rule: do not bury the lead. If a slide, section, or document has a direct point or takeaway, that point belongs in the heading/title itself — not just a topic label with the point buried in the body.

**Why:** Given while iterating on a slideshow presentation ([[project_claritySeed_overview_variants]]) — user first asked for headings that "get to the point" per slide, then generalized it into a standing rule: headings should state the conclusion, not just name the subject. E.g. "Familiar, warm, trustworthy — zero relearning" instead of "Variant A — Original green"; body content should serve only as supporting evidence for the point already stated in the heading.

**How to apply:** Whenever authoring headings/titles for presentations, reports, README sections, PR descriptions, or any content with a clear conclusion — lead the heading with the takeaway itself. Reserve neutral/topic-only headings for cases with no single direct point to make.
